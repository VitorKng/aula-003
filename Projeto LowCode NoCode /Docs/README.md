# Projeto Módulo 3 – Low Code/No Code/Vibecode

## 📌 Desafio Escolhido

O desafio escolhido pelo grupo foi, criar uma aplicação de Calculadora para Orçamento de Materiais de Construção. 

---

## 🖥️ Protótipo

O protótipo funciona para automatizar orçamentos de compras em lojas e-commerce para artigos de construção civil.
https://gemini.google.com/share/b9ce94d0786b
---

## ⚙️ Plataforma Utilizada

- Nome da plataforma "Google Canva".

- Justificativa da escolha: Pela facilidade e praticidade na criação de protótipos.

## 📚 Reflexão Crítica

Explique como o grupo lidou com as limitações e quais soluções criativas foram propostas para contorná-las.

O protótipo não estava gerando o orçamento de dois ou mais itens no preço final. Com isso refinamos o prototipo usando LLM enviando um prompt explicando o problema, e definindo a solução.
Quando tentamos somar um item houve um erro no console e utilizamos um atalho do LLM para corrigir o erro.
Após esta alteração a LLM alterou partes do prototipo em um idioma diferente do utilizado anteriormente, após a identificação do erro damos um comando para a LLM alterar para a forma correta.
